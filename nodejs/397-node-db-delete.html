397. Delete database records using Node.js

Demonstrates removing a document from the database using Mongoose's findByIdAndDelete().

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const Student = require('./models/Student');

async function deleteStudent(id) {
  await Student.findByIdAndDelete(id);
  console.log('Student deleted successfully');
}
deleteStudent('someId');
