422. Test REST APIs using Postman

Explains the workflow for testing the Express REST APIs above using Postman, a popular API testing tool.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
Steps to test with Postman:
1. Start your Express server locally: node server.js  (e.g. running on http://localhost:3000)
2. Open Postman and create a new request.
3. Set the request method (GET, POST, PUT, DELETE) to match the route you want to test.
4. Enter the full URL, e.g. http://localhost:3000/api/students
5. For POST/PUT requests: go to the "Body" tab, select "raw" + "JSON", and enter your JSON payload,
   e.g. { "name": "Shaik Abdulkalam", "course": "CSE AI/ML", "cgpa": 8.28 }
6. Click "Send" and inspect the response status code and JSON body returned.
7. Save requests into a "Collection" so the whole API can be re-tested with one click later.
