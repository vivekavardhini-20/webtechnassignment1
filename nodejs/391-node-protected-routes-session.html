391. Create protected routes using session authentication

Demonstrates a middleware that checks req.session before allowing access to a protected route.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
function requireLogin(req, res, next) {
  if (!req.session.user) {
    return res.status(401).send('Please log in first');
  }
  next();
}

app.get('/dashboard', requireLogin, (req, res) => {
  res.send(`Welcome to your dashboard, ${req.session.user}!`);
});
// (Assumes express-session middleware is already configured earlier, as in the previous example)
