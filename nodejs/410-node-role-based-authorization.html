410. Implement Role-Based Authorization

Demonstrates restricting access based on a user's role (e.g. 'admin' vs 'user'), not just whether they're logged in.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
function authorizeRole(requiredRole) {
  return (req, res, next) => {
    if (req.user.role !== requiredRole) {
      return res.status(403).json({ error: `Requires ${requiredRole} role` });
    }
    next();
  };
}

app.get('/admin/dashboard', verifyToken, authorizeRole('admin'), (req, res) => {
  res.json({ message: 'Welcome to the admin dashboard!' });
});
