412. Restrict specific routes based on user roles

Demonstrates applying different role checks to different routes within the same application.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
app.get('/reports', verifyToken, authorizeRole('admin'), (req, res) => {
  res.json({ report: 'Confidential admin-only report data' });
});

app.get('/my-orders', verifyToken, (req, res) => {
  // any logged-in user (any role) can access this one
  res.json({ orders: ['Order #1', 'Order #2'] });
});
