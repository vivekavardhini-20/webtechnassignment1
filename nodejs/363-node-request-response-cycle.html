363. Demonstrate the Request-Response Cycle in a server-side application

Demonstrates logging the full lifecycle of a request as it comes in and a response is sent back.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const http = require('http');

const server = http.createServer((req, res) => {
  console.log(`[REQUEST] ${req.method} ${req.url} received at ${new Date().toISOString()}`);

  res.writeHead(200, { 'Content-Type': 'application/json' });
  const responseBody = JSON.stringify({ message: 'Response sent back to client', path: req.url });
  res.end(responseBody);

  console.log('[RESPONSE] Sent back to client.');
});

server.listen(3000, () => console.log('Server ready - watch the console as you make requests.'));
