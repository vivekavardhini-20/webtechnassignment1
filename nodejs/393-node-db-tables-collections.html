393. Create and manage database tables/collections

Demonstrates defining a MongoDB collection's shape using a Mongoose Schema and Model.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const mongoose = require('mongoose');

const studentSchema = new mongoose.Schema({
  name: { type: String, required: true },
  course: String,
  cgpa: Number,
  createdAt: { type: Date, default: Date.now }
});

// 'Student' becomes a MongoDB collection named 'students'
const Student = mongoose.model('Student', studentSchema);
module.exports = Student;
