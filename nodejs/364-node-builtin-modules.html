364. Create a Node.js application using built-in modules

Demonstrates using several of Node's built-in modules together: os, path and fs.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const os = require('os');
const path = require('path');

console.log('Platform:', os.platform());
console.log('Free memory (MB):', Math.round(os.freemem() / 1024 / 1024));
console.log('CPU cores:', os.cpus().length);

const filePath = '/project/src/app.js';
console.log('File name:', path.basename(filePath));
console.log('Directory:', path.dirname(filePath));
console.log('Extension:', path.extname(filePath));
