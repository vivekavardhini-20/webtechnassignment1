407. Implement Password Verification

Demonstrates comparing a plain-text password entered at login against the stored bcrypt hash.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const bcrypt = require('bcrypt');

async function verifyPassword(plainPassword, storedHash) {
  const isMatch = await bcrypt.compare(plainPassword, storedHash);
  console.log(isMatch ? 'Password correct!' : 'Password incorrect!');
  return isMatch;
}
// Example: verifyPassword('mySecret123', hashedPasswordFromDatabase);
