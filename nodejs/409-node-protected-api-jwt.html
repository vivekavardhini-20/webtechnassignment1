409. Create Protected API Routes using authentication

Demonstrates applying the JWT verification middleware to protect a specific route.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
// (Assumes verifyToken middleware from the JWT example above)

app.get('/api/profile', verifyToken, (req, res) => {
  res.json({ message: `Welcome, ${req.user.username}!`, data: 'This is protected data.' });
});

app.get('/api/public', (req, res) => {
  res.json({ message: 'This route is open to everyone.' });
});
