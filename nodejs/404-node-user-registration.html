404. Implement User Registration

Demonstrates a registration endpoint that hashes the password before storing the new user.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const bcrypt = require('bcrypt'); // npm install bcrypt

app.post('/register', async (req, res) => {
  const { username, password } = req.body;
  const hashedPassword = await bcrypt.hash(password, 10); // 10 = salt rounds
  const newUser = { username, password: hashedPassword };
  users.push(newUser); // in a real app, save this to a database
  res.status(201).json({ message: 'User registered successfully', username });
});
