418. Implement a DELETE REST API

Demonstrates a DELETE endpoint that removes a resource and returns a 204 No Content response.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
app.delete('/api/students/:id', (req, res) => {
  const exists = students.some(s => s.id === Number(req.params.id));
  if (!exists) return res.status(404).json({ error: 'Student not found' });
  students = students.filter(s => s.id !== Number(req.params.id));
  res.status(204).send(); // 204 = No Content (successful delete, nothing to return)
});
