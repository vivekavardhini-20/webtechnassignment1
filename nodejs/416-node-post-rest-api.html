416. Implement a POST REST API

Demonstrates a POST endpoint that creates a new resource from the request body.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
app.post('/api/students', (req, res) => {
  const { name, course, cgpa } = req.body;
  if (!name) return res.status(400).json({ error: 'Name is required' });
  const newStudent = { id: Date.now(), name, course, cgpa };
  students.push(newStudent);
  res.status(201).json(newStudent); // 201 = Created
});
