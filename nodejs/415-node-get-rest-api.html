415. Implement a GET REST API

Demonstrates a GET endpoint that returns a filtered/paginated list of resources.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
app.get('/api/students', (req, res) => {
  const { course } = req.query;
  let result = students;
  if (course) result = students.filter(s => s.course === course);
  res.status(200).json(result);
});
