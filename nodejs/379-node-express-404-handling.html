379. Implement 404 / Not Found route handling

Demonstrates a catch-all middleware placed last in the chain to handle any route that wasn't matched.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const express = require('express');
const app = express();

app.get('/', (req, res) => res.send('Home Page'));
app.get('/about', (req, res) => res.send('About Page'));

// This middleware only runs if NO earlier route matched the request
app.use((req, res) => {
  res.status(404).send('404 - Page Not Found: ' + req.originalUrl);
});

app.listen(3000, () => console.log('Server running on port 3000'));
