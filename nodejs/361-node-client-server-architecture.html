361. Implement a basic Client-Server Architecture using Node.js

Demonstrates the basic client-server model: a Node.js server listens for requests and a client (browser) sends them.

⚠ This is server-side Node.js code. It cannot run inside a static browser HTML file — copy it into a .js file and run it with node filename.js (after npm installing any packages used).
const http = require('http');

const server = http.createServer((req, res) => {
  // This function runs every time a CLIENT sends a REQUEST to this SERVER
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello from the server! You requested: ' + req.url);
});

server.listen(3000, () => {
  console.log('Server listening on http://localhost:3000');
});
// Run with: node server.js, then open http://localhost:3000 in a browser (the client).
